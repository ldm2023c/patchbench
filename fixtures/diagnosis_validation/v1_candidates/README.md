# Diagnosis Validation v1 candidates

Draft human-authoring inputs. This directory is not a frozen validation suite.
Semantic candidates contain Blind evidence only and intentionally contain no Human Gold.

Human Gold authors may inspect only candidate-inventory.json and the selected
semantic-XX directory, including its task, base source, and Blind Bundle. Do not
inspect _support/, this generator, or candidate-construction tests until that
case's Human Gold has been authored and its identity locked. _support/ is
machine-verification infrastructure and is not part of an authoring packet.
